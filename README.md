# EzVisuals
1. Додай EzVisuals.java та EzMenu.java в src/main/java/com/ezvisuals/
2. Запуш на GitHub -> вкладка Actions -> build -> Artifacts -> ezvisuals-jar
3. Бери jar без -sources, клади в mods разом з Fabric API.

Версії змінюються в gradle.properties (https://fabricmc.net/develop).
Для іншої версії MC зміни також "minecraft" у fabric.mod.json.
